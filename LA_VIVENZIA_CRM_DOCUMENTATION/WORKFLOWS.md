# Workflows

## Lifecycle
Lead discovered → preliminary classification → duplicate check → creation → assignment → contact SLA → interaction → qualification → interest → discussion → onboarding → verification → approval → activation → growth.

## Model
**Trigger → Condition → Action**

Examples:
- Lead created → score above threshold → assign senior coordinator.
- Lead created → referral source → notify owner.
- Interested → no follow-up → create task.
- Document uploaded → verification required → notify onboarding expert.
- Onboarding complete → checks pass → approval task.
- Approval → approved → activation workflow.

## Human approval
Partner approval/rejection, permanent deletion, ownership changes outside policy, commercial terms and sensitive external communication.

## Reliability
Every automated workflow needs owner, retry behaviour, idempotency, auditability, failure visibility and rollback/disable capability.
