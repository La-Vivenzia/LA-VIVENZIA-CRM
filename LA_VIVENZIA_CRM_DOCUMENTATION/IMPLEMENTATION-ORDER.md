# Recommended Implementation Order

1. Foundation: clean fork, Git, baseline, licensing, CI.
2. Design system: tokens, typography, navigation, layout, light/dark, mobile.
3. Data model: People, Organisations, Leads, Experiences, Properties, Partners, Activities, Tasks, Documents, Onboardings, Problems.
4. Operational gaps: notifications, assignment, round robin, SLA, partner onboarding, mobile capture.
5. Communications: email, follow-up, timeline, templates, approval boundaries.
6. Intelligence: classification, score, duplicates, summaries, next-best-action, problems, OCR.
7. Management: control tower, daily brief, analytics, forecasting.
8. Hardening: permissions, audit, security, performance, backups, QA and docs.

Do not optimise AI autonomy before operational data quality and workflow reliability are proven.
