# Licensing & Deployment Review

## Deployment
Prefer self-hosting on La Vivenzia-controlled infrastructure unless the commercial decision changes.

## Review before public launch
Verify the exact license obligations for the selected Twenty version, all modified files/packages, network-access deployment model, enterprise-gated features, third-party dependencies, fonts/assets and external API/AI provider terms.

## Infrastructure
Docker-based deployment, PostgreSQL backups, Redis reliability, object/file storage backups, monitoring, error tracking, secret management, migrations, disaster recovery, restore tests, TLS, rate limiting and network controls.

## Legal gate
This is an engineering checklist, not legal advice. Obtain legal review before public production if licensing obligations are uncertain.
